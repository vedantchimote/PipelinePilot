## Frontend Stack

| Technology | Version | Purpose |
|-----------|---------|---------|
| **React** | 18+ | UI component framework |
| **TypeScript** | 5+ | Type-safe development |
| **React Flow** | v12 | Node-based canvas for visual pipeline editing |
| **Redux Toolkit** | Latest | State management with `redux-undo` for time-travel |
| **Monaco Editor** | Latest | YAML preview with syntax highlighting (VS Code engine) |
| **Vite** | 5 | Build tooling and HMR dev server |
| **Tailwind CSS** | 3 | Utility-first CSS with dark mode support |
| **js-yaml** | Latest | YAML parsing and serialization |

## Key Libraries

| Library | Purpose |
|---------|---------|
| `@reduxjs/toolkit` | Simplified Redux with slices and thunks |
| `redux-undo` | 50-state undo/redo history |
| `@monaco-editor/react` | React wrapper for Monaco Editor |
| `@reactflow/core` | Canvas rendering engine |
| `js-yaml` | YAML ↔ JSON conversion |
| `fast-check` | Property-based testing |

## Development Tools
