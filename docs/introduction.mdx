## What is PipelinePilot?

PipelinePilot is a professional-grade, web-based visual editor for GitLab CI/CD pipelines. Instead of manually writing YAML files, you can visually compose, simulate, and deploy pipelines using an intuitive drag-and-drop interface — complete with AI-powered script generation, live GitLab integration, and a full suite of DevOps power tools.

## Feature Tiers

PipelinePilot ships with 15+ features across three tiers:

### Tier 1 — Quick Wins

<AccordionGroup>
  <Accordion icon="clone" title="Job Duplication">
    Right-click any job node → "Duplicate Job" to instantly clone similar jobs (e.g., `test_unit`, `test_integration`)
  </Accordion>
  <Accordion icon="layer-group" title="Custom Stage Manager">
    Add, remove, rename, and reorder stages beyond the default `build/test/deploy`. Supports custom stages like `lint`, `scan`, `package`, `release`, `cleanup`.
  </Accordion>
  <Accordion icon="paste" title="Paste YAML Import">
    Press `Ctrl+V` anywhere on the canvas to paste an existing `.gitlab-ci.yml` directly — no file dialog needed.
  </Accordion>
  <Accordion icon="terminal" title="Script Snippets">
    Dropdown with common DevOps commands: `npm ci`, `docker build`, `kubectl apply`, `terraform plan` — saves typing.
  </Accordion>
  <Accordion icon="magnifying-glass" title="Job Search / Filter">
    `Ctrl+F` to search jobs by name or stage. Non-matching nodes dim automatically for large pipeline navigation.
  </Accordion>
</AccordionGroup>

### Tier 2 — Power Features

<AccordionGroup>
  <Accordion icon="object-group" title="Multi-Select + Bulk Operations">
    `Shift+Click` to select multiple jobs → floating bulk actions bar for mass delete, stage change, or move operations.
  </Accordion>
  <Accordion icon="diagram-project" title="extends / YAML Anchors UI">
    Create hidden base job templates (`.base_docker`) and let other jobs extend them visually — how 90% of real GitLab CI works.
  </Accordion>
  <Accordion icon="link" title="include Support">
    Reference external YAML files (`include: - template: Auto-DevOps.gitlab-ci.yml`) with a visual manager for local, template, remote, and project includes.
  </Accordion>
  <Accordion icon="play" title="Pipeline Execution Simulator">
    Animate which jobs run in parallel vs sequential based on `needs` dependencies. Shows the actual execution graph with wave-by-wave visualization.
  </Accordion>
  <Accordion icon="table-cells" title="Auto-Layout">
    One-click "Organize" button that auto-arranges all nodes by stage and dependency flow into neat, readable rows.
  </Accordion>
</AccordionGroup>

### Tier 3 — Premium Differentiators

<AccordionGroup>
  <Accordion icon="cloud-arrow-up" title="Live GitLab Push">
    Connect to the GitLab API and push `.gitlab-ci.yml` directly to any branch — complete with project selection, commit messages, and token management.
  </Accordion>
  <Accordion icon="code-compare" title="Pipeline Diff View">
    Compare current pipeline with a saved snapshot or pasted YAML — shows added, removed, and changed jobs with color-coded indicators.
  </Accordion>
  <Accordion icon="note-sticky" title="Job Annotations">
    Add sticky notes and comments to any job — displayed as yellow notes on nodes. Great for team documentation and code reviews.
  </Accordion>
  <Accordion icon="globe" title="Environment Flow Diagram">
    Visualize deploy targets: `staging → production` with approval gates. Auto-detects environments and manual approval requirements.
  </Accordion>
  <Accordion icon="microchip" title="AI Script Helper">
    Describe what a job should do in plain English → auto-generates production-ready script blocks with recommended Docker images. Supports 18+ tech stacks.
  </Accordion>
</AccordionGroup>

## Why PipelinePilot?

Traditional YAML editing for CI/CD pipelines has several challenges:

- **Syntax Errors**: Easy to make indentation or formatting mistakes
- **Complex Dependencies**: Hard to visualize job dependencies and execution order
- **Repetition**: Lots of duplicated configuration across jobs
- **Learning Curve**: Requires memorizing GitLab CI/CD YAML syntax
- **No Simulation**: Can't see what will run in parallel without deploying

PipelinePilot solves these with:

✅ **Visual Clarity**: See your entire pipeline structure at a glance  
✅ **Error Prevention**: Form-based configuration prevents syntax errors  
✅ **Smart Optimization**: Automatic YAML anchors/aliases reduce duplication  
✅ **Instant Feedback**: Real-time validation catches issues before commit  
✅ **AI-Powered**: Generate scripts from descriptions, not memory  
✅ **Direct Push**: Deploy to GitLab without leaving the editor

<Steps>
  <Step title="Install Dependencies">

  </Step>
  <Step title="Start Development Server">
    Run `npm run dev` and open the application at `http://localhost:5173`
  </Step>
  <Step title="Create Your First Pipeline">

## Technology Stack

PipelinePilot is built with modern web technologies:

- **React 18+** with TypeScript for type-safe component development
- **React Flow v12** for the node-based canvas interface
- **Redux Toolkit** with redux-undo for state management and time-travel
- **Monaco Editor** for YAML preview (same engine as VS Code)
- **Vite 5** for blazing-fast development builds
- **Tailwind CSS** for responsive dark/light mode UI
- **js-yaml** for YAML parsing and generation
