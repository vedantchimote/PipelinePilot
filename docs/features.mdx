## Feature Overview

PipelinePilot ships with 15+ features organized into three tiers, plus a full set of core editing capabilities.

| Tier | Features | Focus |

## Tier 1 — Quick Wins

### 1. Job Duplication

Right-click any node to access the context menu:

- **Edit**: Open the property panel
- **Duplicate Job**: Clone with auto-incremented name (`job_1` → `job_1_copy`)
- **Delete**: Remove the job and clean up dependencies

### 2. Custom Stage Manager

<Note>
  Accessible from the **Stages** button in the center toolbar pill.
</Note>

Premium modal for managing pipeline stages:

- **Add/remove stages** beyond the default `build`, `test`, `deploy`
- **Rename stages** inline with validation
- **Reorder** with numbered rows
- **Stage icons** per type (build, test, deploy, scan, lint, etc.)
- **Auto-sort** capability
- Supports custom stages: `lint`, `scan`, `package`, `release`, `cleanup`

### 3. Paste YAML Import

Press `Ctrl+V` anywhere on the canvas (not in an input field):

- **Auto-detects** YAML content by checking for `stages:`, `script:`, or `stage:` keywords
- **Parses** and imports the entire pipeline
- **Shows toast** notification on success
- **Error modal** with line/column info on parse failure

### 4. Script Snippets

Dropdown in the PropertyPanel's Scripts section with pre-built commands:

**Categories:**
- **Package Managers**: `npm ci`, `pip install`, `go mod download`
- **Build Tools**: `docker build`, `mvn package`, `cargo build`
- **Deployment**: `kubectl apply`, `terraform plan`, `helm upgrade`
- **Testing**: `npm test`, `pytest`, `go test`

### 5. Job Search / Filter

Press `Ctrl+F` to toggle the search bar:

- **Real-time filtering** by job name or stage
- **Visual dimming**: Non-matching nodes drop to 30% opacity
- **Press Escape** to clear search and restore all nodes
- Efficient for pipelines with 20+ jobs

## Tier 2 — Power Features

### 6. Multi-Select + Bulk Operations

<Note>
  Hold `Shift` and click nodes to add them to the selection.
</Note>

- **Cyan highlight ring** on multi-selected nodes
- **Floating BulkActionsBar** appears at bottom-center:
  - Shows count: `3 selected`
  - **Move to Stage**: Dropdown to batch-reassign stages
  - **Delete All**: Bulk delete with dependency cleanup
  - **Clear Selection**: Deselect all
- **Press Escape** to clear selection

### 7. extends / YAML Anchors UI

Visual template inheritance — how 90% of production GitLab CI works:

- **Extends dropdown** in PropertyPanel's Basic section
- Lists all **hidden job templates** (jobs starting with `.`)
- When set, emits `extends: .base_docker` in YAML output
- **Parsed on import**: Existing `extends` fields are preserved

```yaml
# Generated YAML with extends
.base_docker:
  image: docker:24
  services:
    - docker:24-dind

build_image:
  extends: .base_docker
  stage: build
  script:
    - docker build -t $IMAGE .
```

### 8. include Support

<Note>
  Accessible from the **Includes** button in the center toolbar pill.
</Note>

Include Manager modal for referencing external YAML:

| Type | Example | Use Case |
|------|---------|----------|
| **Local** | `/path/to/.gitlab-ci.yml` | Monorepo shared configs |
| **Template** | `Auto-DevOps.gitlab-ci.yml` | Official GitLab templates |
| **Remote** | `https://example.com/ci.yml` | External configurations |
| **Project** | `group/project` + ref + file | Cross-project includes |

- Rendered at the **top of YAML output** as `include:` block
- Parsed correctly from imported YAML
- Add/remove with visual list management

### 9. Pipeline Execution Simulator

<Note>
  Toggle from the **Simulate** button in the center toolbar pill.
</Note>

Floating panel in the bottom-right corner:

- **Computes execution waves** based on stage ordering and `needs` dependencies
- Shows which jobs run **in parallel** (Wave 1: `build_app`, `build_docker`)
- Shows which jobs run **sequentially** (Wave 2: `test_unit`, Wave 3: `deploy`)
- **Run** button animates through waves:
  - Green glow on active nodes
  - Spinner on current wave
  - Checkmarks on completed waves
- Footer shows: `3 waves · 6 jobs`

### 10. Auto-Layout

One-click organization:

- **Layout button** in the center toolbar pill
- Groups jobs by their **assigned stage**
- Arranges in neat rows: 280px width, 40px horizontal gap
- 200px vertical gap between stage groups
- Instantly cleans up messy pipelines after heavy editing

## Tier 3 — Premium Differentiators

### 11. Live GitLab Push

<Note>
  Cloud-upload icon (↑) in the right toolbar section.
</Note>

Push `.gitlab-ci.yml` directly to a GitLab branch:

- **GitLab URL**: Defaults to `https://gitlab.com`, supports self-hosted
- **Personal Access Token**: `glpat-...` (not stored in localStorage for security)
- **Project ID / Path**: Numeric ID or `group/project` path
- **Branch**: Target branch (default: `main`)
- **Commit Message**: Customizable
- **API Flow**: Tries `PUT` (update) first, falls back to `POST` (create)
- **Status indicators**: Success (green), Error (red with message), Pushing (spinner)
- Persists URL/project/branch in localStorage for convenience

### 12. Pipeline Diff View

<Note>
  Clipboard icon in the right toolbar section.
</Note>

Compare current pipeline with a previous version:

**Two modes:**
- **Saved Snapshot**: Save current state → compare later after edits
- **Paste YAML**: Paste any `.gitlab-ci.yml` to compare against

**Diff output:**
| Indicator | Color | Meaning |
|-----------|-------|---------|
| `+` | 🟢 Green | Job added |
| `−` | 🔴 Red | Job removed |
| `~` | 🟡 Yellow | Job changed (with specific changes listed) |
| `=` | Gray | Unchanged (count shown) |

**Change details**: `stage: build → test`, `script modified`, `dependencies changed`

### 13. Job Annotations

Sticky notes for documentation:

- **Notes section** in PropertyPanel with textarea
- Annotations appear on job nodes as **yellow sticky notes** with left border
- Useful for:
  - Team documentation
  - Code review comments
  - Explaining complex job configurations
  - TODO notes during pipeline development

### 14. Environment Flow Diagram

<Note>
  Globe icon (🌐) in the right toolbar section.
</Note>

Visualize deployment targets:

- **Extracts environments** from jobs using the `environment:` field
- **Auto-sorts** by deployment stage: `dev → staging → uat → production`
- **Shows approval gates**: Amber badge on jobs with `when: manual`
- **Horizontal flow diagram** with arrows between environments
- **Legend**: Manual approval (amber) vs Auto-deploy (green)
- Shows jobs assigned to each environment

### 15. AI Script Helper

<Note>
  Purple **AI** button in PropertyPanel's Scripts section.
</Note>

Describe what a job should do → get production-ready scripts:

**Supports 18+ tech stacks:**

| Category | Technologies |
|----------|-------------|
| **JavaScript** | Node.js, npm, Jest, ESLint |
| **Python** | pip, pytest, Django, Flask |
| **Containers** | Docker build & push, registry login |
| **Orchestration** | Kubernetes (kubectl), Helm |
| **Infrastructure** | Terraform, Ansible |
| **Languages** | Go, Rust, Java (Maven) |
| **Cloud** | AWS (S3, CloudFront, Lambda) |
| **Security** | npm audit, Snyk, SAST |
| **Notifications** | Slack webhooks |
| **Database** | Migrations, seeding |

**Features:**
- **Quick suggestion chips**: Click to populate common tasks
- **Script preview**: Review generated commands before applying
- **Image recommendation**: Suggests the right Docker image
- **Append mode**: Generated scripts are added to existing script, not replaced
