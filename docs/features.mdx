## Core Features

### Visual Pipeline Canvas

<img src="/images/canvas-overview.png" alt="Canvas Overview" />

The heart of the application is the visual canvas powered by React Flow:

<CardGroup cols={2}>
  <Card title="Drag & Drop" icon="hand">
    Drag jobs around the canvas to organize your pipeline visually
  </Card>
  <Card title="Zoom & Pan" icon="magnifying-glass">
    Navigate large pipelines with smooth zoom and pan controls
  </Card>
  <Card title="Stage Swim Lanes" icon="layer-group">
    Visual grouping of jobs by stage for better organization
  </Card>
  <Card title="Dependency Edges" icon="arrow-right-arrow-left">
    Visual arrows showing job dependencies and execution order
  </Card>
</CardGroup>

**Key Capabilities:**
- Add jobs with a single click
- Create dependencies by dragging between jobs
- Automatic cycle detection prevents invalid pipelines
- Real-time position updates
- Stage-based auto-layout
- Visual indicators for job status (valid, error, trigger)

### Job Configuration Panel

<img src="/images/property-panel.png" alt="Property Panel" />

Comprehensive form-based configuration for every job property:

<Tabs>
  <Tab title="Basic">
    - **Job Name**: Unique identifier for the job
    - **Stage**: Pipeline stage (build, test, deploy, etc.)
    - **Image**: Docker image to use
    - **Tags**: Runner tags for job execution
    - **When**: Execution condition (on_success, on_failure, always, manual)
  </Tab>
  
  <Tab title="Scripts">
    - **Script**: Main commands to execute
    - **Before Script**: Commands to run before main script
    - **After Script**: Commands to run after main script (always executed)
  </Tab>
  
  <Tab title="Artifacts">
    - **Paths**: Files/directories to preserve
    - **Exclude**: Patterns to exclude
    - **Expire In**: Artifact retention period
    - **Expose As**: Name for UI download
    - **Reports**: Test reports, coverage, etc.
  </Tab>
  
  <Tab title="Cache">
    - **Key**: Cache identifier (supports variables)
    - **Paths**: Directories to cache
    - **Policy**: pull, push, or pull-push
    - **Untracked**: Include untracked files
  </Tab>
  
  <Tab title="Variables">
    - **Key-Value Pairs**: Job-specific variables
    - **Protected**: Only available on protected branches
    - **Masked**: Hidden in job logs
    - **Inherited**: View global variables
  </Tab>
  
  <Tab title="Rules">
    - **If Conditions**: When to run the job
    - **When**: Override execution condition
    - **Allow Failure**: Continue pipeline on failure
    - **Variables**: Rule-specific variables
  </Tab>
  
  <Tab title="Advanced">
    - **Needs**: Explicit dependencies (DAG execution)
    - **Dependencies**: Artifact dependencies
    - **Timeout**: Maximum execution time
    - **Retry**: Retry configuration
    - **Allow Failure**: Continue on failure
    - **Trigger**: Multi-project pipeline triggers
  </Tab>
</Tabs>

### Import & Export

<img src="/images/import-export.png" alt="Import Export" />

Bidirectional YAML synchronization:

<Tabs>
  <Tab title="Import YAML">
    **Import existing `.gitlab-ci.yml` files:**
    - Parses YAML to Pipeline_State
    - Renders jobs on canvas with auto-layout
    - Preserves all job configuration
    - Handles includes and extends
    - Displays parsing errors with line numbers
    - Suggests fixes for common syntax errors
  </Tab>
  
  <Tab title="Export YAML">
    **Export to `.gitlab-ci.yml`:**
    - Generates optimized YAML
    - Uses anchors/aliases for DRY code
    - Orders jobs by stage
    - Preserves comments where possible
    - Ready to commit to repository
  </Tab>
  
  <Tab title="Export JSON">
    **Export Pipeline_State as JSON:**
    - Full pipeline state backup
    - Includes UI metadata (positions, viewport)
    - Can be re-imported later
    - Useful for version control
  </Tab>
</Tabs>
