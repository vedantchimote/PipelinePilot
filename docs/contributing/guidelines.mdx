## Getting Started

### 1. Fork and Clone

```bash
# Fork the repository on GitHub
# Then clone your fork
git clone https://github.com/YOUR_USERNAME/gitlab-cicd-visual-editor.git
cd gitlab-cicd-visual-editor

# Add upstream remote
git remote add upstream https://github.com/original/gitlab-cicd-visual-editor.git
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Create a Branch

```bash
# Create a feature branch
git checkout -b feature/your-feature-name

# Or a bugfix branch
git checkout -b fix/bug-description
```

### 4. Make Changes

Follow our [Code Style Guide](/contributing/code-style) and write tests for your changes.

### 5. Run Tests

```bash
# Run all tests
npm run test

# Run specific test suites
npm run test:unit
npm run test:property
npm run test:integration
npm run test:e2e

# Check coverage
npm run coverage
```

### 6. Commit Changes

Follow [Conventional Commits](https://www.conventionalcommits.org/):

```bash
# Feature
git commit -m "feat: add template search functionality"

# Bug fix
git commit -m "fix: resolve circular dependency detection"

# Documentation
git commit -m "docs: update installation guide"

# Tests
git commit -m "test: add property tests for YAML engine"

# Refactor
git commit -m "refactor: simplify dependency graph algorithm"
```

### 7. Push and Create PR

```bash
# Push to your fork
git push origin feature/your-feature-name

# Create a Pull Request on GitHub
```

## Pull Request Guidelines

### PR Title

Use conventional commit format:

- `feat: add keyboard shortcut for undo`
- `fix: resolve Monaco editor theme issue`
- `docs: improve quickstart guide`
- `test: add E2E tests for import workflow`

### PR Description

Include:

1. **What**: What does this PR do?
2. **Why**: Why is this change needed?
3. **How**: How does it work?
4. **Testing**: How was it tested?
5. **Screenshots**: For UI changes

**Template:**

```markdown
## What
Adds keyboard shortcut (Ctrl+Z) for undo functionality.

## Why
Users expect standard undo shortcuts to work.

## How
- Added event listener for Ctrl+Z
- Dispatches Redux undo action
- Updated keyboard shortcuts panel

## Testing
- Added unit tests for keyboard handler
- Added E2E test for undo workflow
- Manually tested in Chrome, Firefox, Safari

## Screenshots
[Screenshot of keyboard shortcuts panel]
```

### PR Checklist

Before submitting, ensure:

- [ ] Code follows style guidelines
- [ ] Tests pass (`npm run test`)
- [ ] New tests added for new features
- [ ] Documentation updated
- [ ] No console errors or warnings
- [ ] Commits follow conventional format
- [ ] Branch is up to date with main

## Code Review Process

1. **Automated Checks**: CI runs tests and linting
2. **Maintainer Review**: A maintainer reviews your code
3. **Feedback**: Address any requested changes
4. **Approval**: Once approved, your PR will be merged
5. **Celebration**: 🎉 Your contribution is live!

## Reporting Bugs

### Before Reporting

1. **Search existing issues**: Your bug might already be reported
2. **Try latest version**: Bug might be fixed in main branch
3. **Reproduce**: Ensure you can consistently reproduce the bug

### Bug Report Template

```markdown
## Description
Clear description of the bug

## Steps to Reproduce
1. Go to '...'
2. Click on '...'
3. See error

## Expected Behavior
What should happen

## Actual Behavior
What actually happens

## Environment
- OS: [e.g., macOS 13.0]
- Browser: [e.g., Chrome 120]
- Version: [e.g., 1.0.0]

## Screenshots
If applicable

## Additional Context
Any other relevant information
```

## Documentation Contributions

Documentation is in the `docs/` directory using Mintlify.

### Running Docs Locally

```bash
# Install Mintlify CLI
npm install -g mintlify

# Run docs server
cd docs
mintlify dev
```

### Documentation Style

- Use clear, concise language
- Include code examples
- Add screenshots for UI features
- Link to related pages
- Test all code examples
