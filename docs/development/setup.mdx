## Prerequisites

- **Node.js** 18+ (LTS recommended)
- **npm** 9+ or **pnpm**
- **Git**

## Quick Start

<Steps>
  <Step title="Clone the Repository">
    ```bash
    git clone https://github.com/vedantchimote/PipelinePilot.git
    cd PipelinePilot
    ```
  </Step>
  <Step title="Install Dependencies">
    ```bash
    npm install
    ```
  </Step>
  <Step title="Start Dev Server">
    ```bash
    npm run dev
    ```
    Open `http://localhost:5173` in your browser.
  </Step>
</Steps>

## Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start Vite dev server with HMR |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview production build locally |
| `npm run test` | Run unit tests with Vitest |
| `npx tsc --noEmit` | TypeScript type checking |

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `VITE_GITLAB_URL` | `https://gitlab.com` | Default GitLab instance URL |

<Note>
  No environment variables are required for basic development. The app works fully offline with local state.
</Note>
