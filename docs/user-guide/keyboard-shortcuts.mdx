## Quick Reference

PipelinePilot supports keyboard shortcuts for all common operations. Press `Ctrl+/` to toggle the shortcuts panel inside the app.

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo last action |
| `Ctrl+Y` | Redo last undone action |
| `Ctrl+S` | Manual save to localStorage |
| `Ctrl+E` | Export YAML file |
| `Ctrl+V` | Paste YAML import (when canvas is focused) |
| `Ctrl+F` | Toggle job search / filter |
| `Ctrl+/` | Show keyboard shortcuts panel |
| `Shift+Click` | Multi-select nodes |
| `Escape` | Close panel / Clear selection / Clear search |
| `Delete` | Delete selected job |

---

## Context Menu

Right-click any job node to access:

- **Edit** — Open the property panel for the job
- **Duplicate Job** — Clone with auto-incremented name
- **Delete** — Remove the job and clean up dependencies

## Canvas Navigation

| Action | Control |
|--------|---------|
| Pan | Click and drag on empty canvas |
| Zoom | Mouse scroll wheel |
| Fit to view | Click the fit-to-view button (bottom-left) |
| Zoom in/out | Click `+`/`-` buttons (bottom-left) |
