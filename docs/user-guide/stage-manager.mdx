## Overview

The Stage Manager lets you customize your pipeline's stage structure beyond the default `build`, `test`, `deploy`. Real-world pipelines often need stages like `lint`, `scan`, `package`, `release`, and `cleanup`.

## Accessing the Stage Manager

Click the **Stages** button in the center toolbar pill to open the Stage Manager modal.

## Step-by-Step Usage

<Steps>
  <Step title="Open the Stage Manager">
    Click **Stages** in the center toolbar. The modal appears with your current stages listed.
  </Step>
  <Step title="Add a new stage">
    Type a name in the input field at the bottom (e.g., `lint`) and click the **+** button or press Enter.
  </Step>
  <Step title="Reorder stages">
    Stages execute in the listed order — top to bottom. Each stage shows a number indicating its position in the pipeline.
  </Step>
  <Step title="Rename a stage">
    Click directly on any stage name to edit it inline. The name validates in real time — duplicates and empty names are rejected.
  </Step>
  <Step title="Delete a stage">
    Click the trash icon next to any stage to remove it. Jobs assigned to the deleted stage will need to be reassigned.
  </Step>
  <Step title="Apply changes">
    Click **Apply** — the canvas swim lane labels and the Stage dropdown in the PropertyPanel update immediately.
  </Step>
</Steps>

## Common Custom Stages

| Stage | Purpose | Example Jobs |
|-------|---------|-------------|
| `lint` | Code quality checks | ESLint, Prettier, Flake8 |
| `scan` | Security scanning | SAST, dependency audit, Snyk |
| `package` | Build artifacts | Docker image build, npm pack |
| `release` | Publish releases | npm publish, GitHub Release |
| `cleanup` | Remove temp resources | Cleanup test databases |
| `notify` | Send notifications | Slack webhook, email |

## Stage Icons

The Stage Manager automatically assigns icons based on stage name keywords:

| Keyword | Icon |
|---------|------|
| `build`, `compile` | 🔨 Hammer |
| `test`, `spec` | 🧪 Flask |
| `deploy`, `release` | 🚀 Rocket |
| `lint`, `format` | 📐 Ruler |
| `scan`, `security` | 🔒 Lock |
| `package`, `bundle` | 📦 Package |
| Other | ⚙️ Gear |

<Tip>
  Stages defined in the Stage Manager automatically appear in the Stage dropdown when configuring jobs in the PropertyPanel. You don't need to manually sync them.
</Tip>
